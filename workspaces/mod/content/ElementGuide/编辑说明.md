# 编辑元素图鉴

本文件是编辑指南，不显示为游戏条目。`index.json` 和各 `.md`、图片文件随 Mod 一起分发；无需 Unity Editor，也无需重新编译 DLL。

开发时编辑项目中的 `workspaces/mod/content/ElementGuide/`。构建会复制到 `artifacts/mod/HollowElements/ElementGuide/`。玩家实际使用的是游戏 `Managed/Mods/HollowElements/ElementGuide/`。修改项目源文件不会自动改动已经安装的版本；可复制到游戏目录测试。

## 目录与顺序

`index.json` 中 `Categories` 的顺序是分类顺序，各分类的 `Entries` 顺序是条目顺序。最小例子：

```json
{
  "Version": 1,
  "Title": "元素图鉴",
  "Layout": { "FontSize": 24, "SidebarWidth": 300, "ImageMaxHeight": 480, "Spacing": 14 },
  "Categories": [
    {
      "Title": "反应说明",
      "Entries": [
        { "Id": "example", "Title": "示例条目", "File": "reactions/example.md" }
      ]
    }
  ]
}
```

- `Id` 必须唯一。`File` 相对于 ElementGuide 文件夹，所有文本使用 UTF-8。
- 给 Boss 条目添加 `"Scenes": ["GG_Hornet_1"]` 等场景名称，进入该神居场景后打开图鉴会自动选中这个条目。多个场景可共用一个条目，场景名不得重复分配。中庭、工坊等未映射房间保留上次选择；只在打开页面时定位，阅读中可自由切换其他条目。
- 可给单个条目增加 `"Layout": { "FontSize": 26, "ImageMaxHeight": 300 }`，未填写项继承全局。
- 全局字号 18–40，侧栏宽 200–480，图片最高 64–700，段落间距 4–40。实际侧栏最多占可用宽度 32%，图片等比缩放。
- 全局目录最多 500 个条目。主目录最大 1MB，每篇正文最大 512KB。

## 支持的 Markdown

支持 `#` / `##` / `###` 标题、空行分段、`-` 或 `*` 列表、数字列表、`> 提示`、`**加粗**`、行内代码、`---` 分隔线、基础表格及独立一行的插图。长段落自动换行，整页自动滚动。

```markdown
# 条目标题

这里是正文，**这里加粗**。

- 一个机制
- 另一个机制

![这里是图片说明](../images/example.png)

> 这里是提示。

| 第一列 | 第二列 |
|---|---|
| 内容 | 内容 |
```

图片路径相对于正文文件，不得超出 ElementGuide 文件夹。推荐 PNG，也支持 Unity 能读取的 JPG；每张不超过 16MB、边长不超过 4096。缺图会显示占位说明，其他正文仍可阅读。图片不自动裁切，透明背景可用。

这是受限 Markdown 阅读器，不执行 HTML、JavaScript、CSS；普通链接显示链接文字，不打开网页。复杂嵌套列表、代码块高亮、合并单元格尚未提供。图片尺寸、字号与间距通过 JSON 调整，不手填屏幕坐标。

## 引用当前游戏数值

正文中的以下占位符在显示时替换：

- `{{DirectDamageReduction}}`：当前直接伤害减伤，例如 `55%`。
- `{{DirectDamageMultiplier}}`：当前保留倍率，例如 `0.45`。
- `{{NailDamage}}`：当前未减伤基础骨钉伤害。
- `{{PlayerElectroSeconds}}`：玩家感电基础总时长。
- `{{Reactions.ForwardMultiplier}}` 等：`RuleConfig.Reactions` 的数值字段。
- `{{Attacks.BlackShriek.MaxApplicationsPerCast}}` 等：指定攻击配置的数值字段。

字段区分大小写，只读取数值，未知字段会显示“未知参数”。正文是规则说明，不会反过来修改战斗机制。Boss 专属硬编码数值需要作者随代码变动更新。

## 查看修改

重新打开图鉴会检查目录和正文的修改时间、文件大小；有变化才重新读取，没有修改时复用已加载的界面。当前页插图也会检查文件变化，最近使用的插图有缓存。修改文件后，关闭并重新打开图鉴即可查看。

右下角“重新加载”始终强制读取文档并清空图片缓存，调试模式下也可按 F4。若使用工具替换文件时保留了相同的修改时间和文件大小，请使用“重新加载”。损坏的 JSON、错误布局、缺失正文会提示具体问题，并保留上一次有效内容。

图鉴目录、正文、提示和表格全部使用 `TextMeshProUGUI`，统一采用 `Font/` 中原神字体的 SDF 字库，共预制 33,552 个字符，不混用官方或系统字体。常用正文与菜单字符集中在主图集，其他字符按需加载同字体图集页。编辑一般中文无需重新烘焙字体；原字体本身不包含的字符仍需替换或扩充源字体。

如需替换字库源字体，修改 `generate_element_guide_font.py` 的字体路径后运行该工具生成 SDF 页，再重新构建／复制 ElementGuide 文件夹。此步骤无需 Unity Editor，不需要修改或重新编译 DLL 的逻辑。

## 操作与打包

图鉴目录顶部另有内置「元素配置」入口，不属于外部目录条目，也不新增原版背包页。沿用原招式图标，只显示已解锁招式；白／黑法术共用同一元素。确认进入后上下选择、左右或确认修改，返回目录或关闭图鉴。修改在关闭图鉴／离开页面时自动保存。

Mod 菜单的「允许非长椅配置元素」独立于调试模式，新安装默认开启；关闭时长椅外只能查看，左右、确认和鼠标点击都不会更改元素，并提示在长椅配置。元素配置仅保留在「元素系统」图鉴页中；独立配置面板、R 快捷键和长椅文字提示已移除。

原版背包地图之后是图鉴，继续向右回到物品栏；也可用 Mod 菜单配置快捷键，默认 F5。原版背包无法打开的死亡、过场等状态也不能通过快捷键强行打开图鉴。

手柄上下选择、确认进入正文、上下或右摇杆滚动、返回退回目录再关闭；肩键保持原版翻页。键鼠支持点击和滚轮。阅读图鉴时暂停，关闭、换页或卸载后恢复原速度。

图鉴内按数字 1（含小键盘 1）或手柄当前绑定的梦钉键，可直接跳到元素配置并进入招式选择。键盘的梦钉键不会占用此入口，以免与菜单方向键重绑定冲突；独立的配置快捷键已移除。跳转本身不会修改配装，非长椅修改仍受 Mod 菜单开关控制。

Mod 菜单用一个「跳字大小」统一调整伤害与反应，提供 100%、125%、150%、175%、200%、250%，默认 150%。基础字号伤害 48、反应 60（均为此前的两倍）；默认实际字号为 72、90。白色描边、玩家受击时的斜体反应与文字框同步缩放，血条字号保持不变。旧的两项设置迁移时采用较大值。

发布时完整保留 `HollowElements/ElementGuide/`。`workspaces/mod/tools/package_element_guide.py` 会验证目录、正文与所有配图后一起打包，历史发布包不覆盖。

显示与默认值：Mod 菜单可隐藏本 Mod 血条而保留图标；兼容 EnemyHPBar 的可见血条定位。新安装默认允许非长椅配置并显示生命数值，直接伤害减伤默认为20%，已有设置保留。正文截图支持 PNG／JPEG，建议小于1MB；替换或删除引用后使用 sync_element_guide.py 同步清理旧图。


## 直接发布正文（v0.1.9.6）

已回退文本压缩与启动解压，发布包直接包含 MD 和 index.json；启动直接读取，外部编辑和刷新照常工作。保留 ElementGuide 名称。安装更新时移除旧 content.zip 与 .content-state.json，不删除自行编辑的正文或 .incoming 文件。

难度选项：极限减伤65%、困难55%、平衡50%、普通20%、简单0%；新安装默认普通，已有减伤设置按实际数值保留。

## 图鉴媒体优化（v0.1.9.8）

开发工作区保留原始 SDF 和插图；发布构建使用 optimize_guide_media.py 输出派生资源。SDF 采用无损索引透明度 PNG，尺寸、33552 个字形、度量和逐像素透明度不变。截图最长边 960 像素，以较高质量 JPEG 发布；示意图保留 PNG。发布阶段若 PNG 截图改为 JPEG，会同步更新派生 MD 中的引用，开发目录的原文不变。

asset-optimization.json 记录源文件和派生文件校验值。运行时仍直接读取图片、字体及 MD/JSON，不需要启动解压。若替换发布目录内图片，可直接更新对应文件及正文引用；该校验记录仅用于构建验证，不限制运行时外部编辑。
