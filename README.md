# HollowElements

为《空洞骑士》引入元素反应的战斗模组。火、水、雷、冰在攻击与敌人之间交织，让熟悉的神居战斗拥有新的选择。

## 元素与反应

- 分别配置骨钉、法术与剑技的元素，配置页只显示已解锁的招式。
- 加入蒸发、融化、超载、感电、冻结、超导与碎冰，组合增幅、持续伤害、控制和破绽兑现等战斗方式。
- 玩家也会受到元素反应影响，拥有独立的受击效果与状态提示。

## 独立护符与 Boss 机制

- 提供 20 种独立护符，不占原版护符槽，可围绕不同反应构建配装。
- 通用、增幅、剧变、生存分别拥有 1／1／2／1 个槽位；也可放弃增幅护符，额外装备一枚剧变护符。护符仅能在长椅调整。
- 神居 Boss 拥有专属元素机制，可在游戏内图鉴查看。部分 Boss 入场时显示简短提示，随后缩小移至屏幕顶部，可在 Mod 菜单关闭。

## 游戏内「元素系统」

- 从原版背包翻页或按 F5 打开，查看元素配置、护符配装和带插图的机制图鉴。阅读时暂停游戏，支持键鼠与手柄导航。
- 在神居战斗中打开时，自动定位当前 Boss 的条目；按数字 1 或手柄梦之钉键可跳转至元素配置。
- 默认允许非长椅调整元素，也可在 Mod 菜单改为仅限长椅。

## 表现与设置

- 元素染色、反应与持续状态特效、反应音效，以及带描边的伤害／反应跳字。
- 敌人血条显示附着、状态与层数，默认显示当前／最大生命值。可隐藏本 Mod 血条并保留状态图标；安装 EnemyHPBar 时适配其血条位置。
- 「难度」提供极限、困难、平衡、普通、简单五档，默认普通。难度调整玩家对敌直接伤害，极限与困难还会降低反应附伤，不改变敌人原本的对玩家伤害。
- 可调整跳字和反应特效大小、元素染色等选项；内置调试模式与反应测试木桩。

## 使用

目标环境为 Windows 版《空洞骑士》1.5.78.11833 和 Modding API 77。安装匹配的 Modding API 后，将发布包中的 `HollowElements` 文件夹放入游戏的 `Mods` 目录；游戏内可通过背包的「元素系统」页或 F5 查看图鉴和配置。

## 构建

代码位于 `workspaces/mod`，运行所需的源资产位于 `workspaces/art/source`。在 PowerShell 中运行：

```powershell
./workspaces/mod/bootstrap.ps1
./workspaces/mod/build.ps1
python workspaces/mod/tools/prepare_assets.py
```

构建需要本机游戏文件、对应 Modding API 依赖和 Python Pillow；具体配置参见 [代码工作区说明](workspaces/mod/README.md)。构建输出与本地依赖不纳入仓库。

本项目是粉丝创作的非官方模组，与《空洞骑士》及《原神》的权利方无隶属关系。
